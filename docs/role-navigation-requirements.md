# Login and dashboard navigation requirements

Organise navigation buttons inside the appropriate dashboard after login. This document specifies the requested behaviour; it does not indicate that the assessment portal is deployed or production-ready.

## Public login placement

- Place Administrator Login under Administration.
- Place Teacher Login under Staff.
- Place Student Login under Students.
- Keep Parent Login separate.
- Retain Headteacher Login within Staff.

## Administrator dashboard

- School Overview.
- Student and staff management.
- Class and subject assignments.
- Academic year and term settings.
- Scorebook and result publication.
- Reports and overall performance.
- Schemes, learning materials and lesson approvals.
- Authentication settings, password resets and activity logs.

## Teacher dashboard

- Assigned classes and subjects.
- Exercise and examination entry.
- Save Progress and Migrate to Scorebook.
- Assigned-class Scorebook.
- Lesson-note drafts and submission.
- Approved schemes of work.
- Question Bank and Mock Questions.
- Teaching Resources.
- Personal account settings.

## Student dashboard

- Personal dashboard and profile.
- Published results.
- Personal report cards.
- Approved learning materials.
- Assignments, announcements and academic calendar.
- Change Password and Sign Out.

## Headteacher dashboard

- Student management.
- Teaching assignments.
- Lesson approvals.
- Academic-period controls.
- School-wide reports.

## Access and responsive navigation

Show each user only the buttons their role permits. Enforce the same restrictions on the server for pages, mutations, downloads and exports. Teachers may access only assigned classes and subjects; students may access only their own records and permitted resources.

Preserve all authorised buttons in tablet and mobile navigation. Collapsing navigation must not remove access to authorised features or change permissions.
